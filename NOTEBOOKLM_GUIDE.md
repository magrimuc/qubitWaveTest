## 📥 Wege zur Einbindung in NotebookLM

### Option 1: GitHub Raw Links (Empfohlen)
Da das Repository nun auf GitHub unter `magrimuc/qubitWaveTest` liegt, kannst du folgende direkte Raw-Links als Quellen in NotebookLM einfügen:

1. `https://raw.githubusercontent.com/magrimuc/qubitWaveTest/main/README.md`
2. `https://raw.githubusercontent.com/magrimuc/qubitWaveTest/main/NOTEBOOKLM_GUIDE.md`
3. `https://raw.githubusercontent.com/magrimuc/qubitWaveTest/main/MinimalQubit.py`
4. `https://raw.githubusercontent.com/magrimuc/qubitWaveTest/main/Test_MinimalQubit.py`

### Option 2: Dateien hochladen / Google Drive
1. Lade die Dateien `README.md`, `MinimalQubit.py` und `NOTEBOOKLM_GUIDE.md` herunter oder speichere sie in deinem Google Drive.
2. Öffne dein NotebookLM: [fe6fdd55-fb14-4bc1-be46-3d4eba5a2077](https://notebook.google.com/notebook/fe6fdd55-fb14-4bc1-be46-3d4eba5a2077).
3. Klicke auf **"Quellen hinzufügen"** (Add Sources) -> **Google Drive / Datei-Upload** oder **Web-URL**.
